# 家庭健身契约

给家里人使用的健身计划、打卡监督和保证金账本原型。第一版是本地手机网页/PWA，不接真实支付，不做后端同步，数据保存在当前浏览器的 `localStorage`。

## 当前功能

- 爸爸视角：今日训练、本周计划、训练反馈、保证金账本。
- 教练视角：完成率、待确认异常、缺卡账本同步、微信提醒文案。
- 健康安全：疼痛、头晕、胸闷等异常会进入待确认，不直接记罚款。
- 保证金：缺卡按 `10 元/次` 记账，可标记已付或豁免。
- PWA 基础：包含 manifest、图标和简单 service worker。

## 本地运行

```powershell
npm install
npm run dev
```

默认地址：

```text
http://127.0.0.1:4270/
```

本机 `5170-5269` 端口段被 Windows 保留，所以开发端口固定为 `4270`。

## 健康边界

这个原型只用于家庭训练记录和习惯监督，不是医学建议或康复处方。老人训练应量力而行，出现疼痛、头晕、胸闷等情况时先停止训练。

训练安排参考 CDC 对 65 岁以上人群的活动建议：每周包含有氧、肌力和平衡活动，其中肌力活动至少每周 2 天。

参考来源：https://www.cdc.gov/physical-activity-basics/guidelines/older-adults.html
